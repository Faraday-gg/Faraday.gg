# Bitácora

Registro cronológico de lo que hacemos **fuera del código**: Supabase, Vercel, GitHub, cuentas, dominios, claves (sin escribir nunca su valor). Un archivo por mes, `AAAA-MM.md`, con las entradas más recientes arriba.

Formato de cada entrada:

```markdown
## AAAA-MM-DD — Título breve
- **Quién:** nombre (y agente, si lo hubo)
- **Dónde:** servicio y proyecto
- **Qué:** lo que se hizo o se intentó
- **Resultado:** lo que quedó, enlaces a PR o decisiones
```
