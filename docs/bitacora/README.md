# Bitácora

Registro cronológico de lo que hace cada uno: un resumen de cada sesión de trabajo (lo añade la skill [sincronizar](../../.claude/skills/sincronizar/SKILL.md)) y todo lo que se hace **fuera del código**: Supabase, Vercel, GitHub, cuentas, dominios, claves (sin escribir nunca su valor). Un archivo por mes, `AAAA-MM.md`, con las entradas más recientes arriba.

Formato de cada entrada:

```markdown
## AAAA-MM-DD — Título breve
- **Quién:** nombre del colaborador, con <agente>
- **Rama:** `feat/...` (si la hay)
- **Qué:** lista corta de lo que se hizo o se intentó
- **Servicios externos:** servicio y proyecto tocados, o "Ninguno"
- **Comprobaciones:** qué se ejecutó y su resultado
- **Pendiente:** lo que queda, o "Nada"
```
