# Instrucciones para Claude Code

Este proyecto mantiene sus reglas para agentes de IA en [AGENTS.md](AGENTS.md). Léelas y síguelas siempre, en especial el flujo de ramas: nunca trabajes en `main` ni en `preprod`; crea una rama `feat/...` o `fix/...` desde `preprod`, abre una PR hacia `preprod` y entrega al colaborador el resumen, el nombre de la rama, las comprobaciones y el enlace de la PR.
